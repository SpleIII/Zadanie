# hello-static

Статический сайт на чистом HTML + CSS + JS без сборщика и без зависимостей.
Файлы выкладываются на **GitHub Pages** как есть — ровно те, что лежат в
каталоге `public/`.

## Что делает пайплайн

| Шаг | Что происходит |
|---|---|
| Проверка структуры | убедиться, что на месте `index.html`, `style.css`, `script.js` и что они подключены |
| `configure-pages` | подготовить окружение Pages |
| `upload-pages-artifact` | загрузить папку `public/` как артефакт сайта |
| `deploy-pages` | опубликовать сайт |

Сборки нет вообще: GitHub Pages отдаёт файлы как есть.

## Живой сайт

<https://spleiii.github.io/Zadanie/>

## Структура

```
hello-static/
└── public/
    ├── index.html   # разметка страницы
    ├── style.css    # оформление: градиент, карточки, кнопка
    └── script.js    # счётчик кликов
```

Все ссылки внутри страницы относительные (`./style.css`), поэтому сайт
одинаково работает и по пути `/`, и по пути `/Zadanie/`.

## Локальный запуск

```bash
cd projects/hello-static
python -m http.server 8000 --directory public
# открыть http://localhost:8000
```

## Что на странице

* приветственный блок с названием сборки;
* карточка с описанием проекта;
* карточка со счётчиком: кнопка «Увеличить» меняет значение на единицу.
