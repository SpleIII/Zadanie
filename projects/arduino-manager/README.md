# arduino-manager

Менеджер библиотек и плат Arduino с интерфейсом на Go (**Fyne**). Умеет
искать репозитории на GitHub, ставить библиотеки и ядра плат, обновлять
официальный индекс и управлять всем этим из одного окна.

## Что делает приложение

| Раздел | Возможности |
|---|---|
| Libraries | поиск библиотек на GitHub, установка из ZIP или из репозитория |
| Boards | поиск ядер плат, установка, запуск скрипта установки тулчейна |
| Local index | поиск по локальной копии официального `library_index.json` |
| Popular cores | быстрая установка популярных ядер (ESP32, AVR, RP2040 и др.) |
| Configuration | пути к sketchbook и каталогу Arduino15 |

Установка идёт в системные каталоги Arduino, конфигурация хранится в файле
`~/.arduino-manager.conf`.

## Что проверяет пайплайн

| Шаг | Команда | Зачем |
|---|---|---|
| Сборка | `go build` | контроль, что приложение компилируется |
| Релиз | матрица ОС | три бинарника за один прогон |

Публикация происходит по тегу с префиксом проекта: `arduino-manager-v1.0.0`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+F` / `Ctrl+L` | фокус в строке поиска |
| `Ctrl+K` | очистить строку поиска |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | переключение режима |
| `Ctrl+R` | повторить поиск |
| `Esc` | отменить текущую операцию |

## Матрица сборки

| ОС | Файл |
|---|---|
| Linux x64 | `arduino-manager-linux-x64` |
| macOS ARM | `arduino-manager-macos-arm64` |
| Windows x64 | `arduino-manager-windows-x64.exe` |

## Структура

```
arduino-manager/
├── go.mod
├── go.sum
└── main.go    # Manager (логика) и App (интерфейс) в одном файле
```

Приложение разделено на две части внутри одного файла: `Manager` отвечает за
работу с GitHub, индексами и файловой системой, `App` — за окно и виджеты.

## Запуск

```bash
go mod tidy
go run .

# сборка бинарника
go build -o arduino-manager .
```

## Новый релиз

```bash
git tag arduino-manager-v1.0.0
git push origin arduino-manager-v1.0.0
```
