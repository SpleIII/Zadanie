# hex-loader

Загрузчик `.hex`-файлов в Arduino: настольное приложение на Go с интерфейсом
**Fyne**, которое находит подключённые платы, определяет их тип и заливает
прошивку через `arduino-cli`.

## Что делает приложение

* находит платы командой `arduino-cli board list` и показывает их порты;
* определяет FQBN платы либо даёт выбрать его из списка вручную;
* проверяет, установлено ли нужное ядро (`arduino-cli core list`);
* загружает выбранный `.hex` и показывает прогресс;
* предупреждает, если у пользователя нет прав на последовательные порты
  (нужна группа `dialout` или `uucp`).

## Что проверяет пайплайн

| Шаг | Команда | Зачем |
|---|---|---|
| Сборка | `go build` | контроль, что приложение компилируется |
| Релиз | матрица ОС | три бинарника за один прогон |

Публикация происходит по тегу с префиксом проекта: `hex-loader-v1.0.0`.

## Требования на машине разработчика

```bash
# arduino-cli должен быть в PATH
arduino-cli version

# права на порты (Linux)
sudo usermod -a -G dialout $USER
```

Если `arduino-cli` не найден, приложение всё равно запустится, но кнопки
выбора файла, порта и загрузки будут заблокированы.

## Матрица сборки

| ОС | Файл |
|---|---|
| Linux x64 | `hex-loader-linux-x64` |
| macOS ARM | `hex-loader-macos-arm64` |
| Windows x64 | `hex-loader-windows-x64.exe` |

## Структура

```
hex-loader/
├── go.mod
├── go.sum
└── main.go    # окно приложения, работа с arduino-cli, свой рендерер кнопок
```

Всё приложение лежит в одном файле: сюда вынесены и логика, и виджеты, и
собственный рендерер кнопки с рамкой.

## Запуск

```bash
go mod tidy
go run .

# сборка бинарника
go build -o hex-loader .
```
