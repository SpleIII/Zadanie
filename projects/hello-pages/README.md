# hello-pages

React-приложение на Vite, которое собирается в CI и готовится к публикации
на **GitHub Pages**. Отличие от `hello-static`: здесь есть полноценный
сборщик, зависимости из npm и отдельный каталог `dist/` на выходе.

## Что делает пайплайн

| Job | Что происходит |
|---|---|
| `build` | `npm install` → `npm run build` → сборка сохраняется артефактом `pages-spa-dist` |
| `deploy` | загружает артефакт и публикует его на Pages |

Job `deploy` включается переменной репозитория `DEPLOY_SPA=true`: слот
GitHub Pages в монорепозитории один, и сейчас его занимает статический
сайт из `projects/hello-static`. Сборка при этом запускается всегда — она
и служит проверкой, что фронтенд не сломался.

## Путь публикации

Сборка лежит не в корне репозитория, поэтому в `vite.config.js` задан
базовый путь:

```js
export default defineConfig({
  plugins: [react()],
  base: '/Zadanie/',
})
```

Без этой строки ассеты искались бы в корне домена и сайт открывался бы
пустым.

## Структура

```
hello-pages/
├── index.html         # точка входа для Vite
├── package.json       # зависимости и скрипты
├── vite.config.js     # конфигурация сборщика
└── src/
    ├── main.jsx       # монтирование React в #root
    ├── App.jsx        # разметка страницы
    └── index.css      # оформление
```

## Запуск

```bash
cd projects/hello-pages

# разработка с горячей перезагрузкой
npm install
npm run dev

# продакшн-сборка
npm run build
npm run preview
```
